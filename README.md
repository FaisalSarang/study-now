# 🦉 Study NOW

A friendly study planner for exams, tests, quizzes, homework and self-study.
Add a goal, pick the subjects, list the lessons, books, worksheets and practice
for each one, then tick them off as you go (with confetti 🎉).

## 📲 Get the app

Open this link on your phone:

**https://faisalsarang.github.io/study-now/**

Then install it:

- **Android (Chrome):** tap the **Install** button in the app, or the ⋮ menu → **Install app** / **Add to Home screen**.
- **iPhone / iPad (Safari):** tap the **Share** button → **Add to Home Screen**.

It then opens like a normal app, full screen, and works offline.

## Good to know

- Everything is saved **on the phone only** — no account, nothing sent anywhere.
- Use **Settings → Save backup** to keep a copy or move to a new phone.

## For developers

Plain HTML, CSS and JavaScript — no build step. To run locally:

```bash
python -m http.server 8765
```

Then open http://localhost:8765. When you change app files, bump `CACHE` in
`sw.js` so installed copies update.
